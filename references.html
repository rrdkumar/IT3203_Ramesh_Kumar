Research Sources and References

The following resources were used to research HTTP, its evolution, protocols, standards, and related concepts.

  • MDN Web Docs – HTTP

    Comprehensive documentation about HTTP protocols, requests, responses, methods, and status codes.

  • RFC 2616 – HTTP/1.1

    Historical specification describing the HTTP/1.1 protocol and its core communication features.

  • RFC 7540 – HTTP/2

    Defines HTTP/2 and explains improvements such as multiplexing and header compression.

  • RFC 9114 – HTTP/3

    Explains HTTP/3 and its use of the QUIC transport protocol to improve speed and reliability.

  • IETF HTTP Working Group

    Official working group responsible for developing and maintaining HTTP standards.

  • RFC 9110 – HTTP Semantics

    Defines HTTP methods, message semantics, status codes, and general protocol behavior.

  • RFC 9112 – HTTP/1.1

    Provides the current specification for HTTP/1.1 message format and routing.

  • RFC 9113 – HTTP/2

    Updated specification for HTTP/2 including framing and multiplexing features.

  • MDN Web Docs – HTTP Headers

    Reference guide describing common HTTP request and response headers used in web communication.

  • MDN Web Docs – HTTP Status Codes

    Explains status codes such as 200 OK, 404 Not Found, and 500 Internal Server Error.
