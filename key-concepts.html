HTTP Semantics

Defines how requests and responses are structured and interpreted.

Statelessness

Each HTTP request is independent; servers do not store client state.

Methods

Actions clients request: GET, POST, PUT, PATCH, DELETE.

Status Codes

Indicate the result of a request: 2xx success, 4xx client error, 5xx server error.

HTTPS / TLS

Provides encryption, authentication, and integrity for HTTP communication.

Caching

Improves performance by storing responses for reuse.
