HTTP Semantics

HTTP semantics explain how requests and responses should look and how they are understood by browsers and servers.

Statelessness

HTTP is stateless, which means it does not remember past requests. Each request is treated as new.

Methods

HTTP methods tell the server what action to take. Common methods are: GET, POST, PUT, and DELETE.

Status Codes

Status codes show the result of a request. For example: 200 means success, 404 means not found, and 500 means server error.

HTTPS / TLS

HTTPS is the secure version of HTTP. It uses TLS to protect data so information cannot be read by others.

Caching

Caching saves copies of files so websites load faster the next time you visit them.
