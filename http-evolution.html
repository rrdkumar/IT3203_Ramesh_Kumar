HTTP/0.9

HTTP/0.9 was the first version. It only supported the GET method and could return simple HTML pages. It was very basic.

HTTP/1.0

HTTP/1.0 added status codes and headers. It allowed more methods, but the connection closed after each request, which made it slower.

HTTP/1.1

HTTP/1.1 improved speed by keeping the connection open. It also added better caching and made host headers required.

HTTP/2

HTTP/2 is faster because it uses multiplexing, header compression, and binary framing. This helps websites load quicker.

HTTP/3 and QUIC

HTTP/3 uses QUIC instead of TCP. This reduces delays and makes connections more reliable, especially on modern networks.
