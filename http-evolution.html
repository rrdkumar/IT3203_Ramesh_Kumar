HTTP/0.9

HTTP/0.9 was the first version of HTTP. It only supported the GET method and returned simple HTML pages.

HTTP/1.0

HTTP/1.0 added important features such as headers and status codes. It supported additional methods but closed the connection after each request and response.

HTTP/1.1

HTTP/1.1 improved efficiency by introducing persistent connections, better caching, chunked transfer encoding, and mandatory host headers.

HTTP/2

HTTP/2 introduced multiplexing, header compression, and binary framing. These improvements reduced latency and improved performance on modern websites.

HTTP/3 and QUIC

HTTP/3 uses the QUIC protocol instead of TCP. This reduces connection delays, improves reliability, and provides faster page loading on modern networks.
