HTTP/0.9

HTTP/0.9 was the first version. It only supported the GET method and returned simple HTML pages.

HTTP/1.0

HTTP/1.0 added status codes and headers. It allowed more methods but closed the connection after each request.

HTTP/1.1

HTTP/1.1 improved speed with persistent connections, better caching, and required host headers.

HTTP/2

HTTP/2 uses multiplexing, header compression, and binary framing to improve performance.

HTTP/3 and QUIC

HTTP/3 uses QUIC instead of TCP, reducing delays and improving reliability on modern networks.
