HTTP/0.9

Introduced in 1991, HTTP/0.9 supported only simple GET requests and returned raw HTML.

HTTP/1.0

Added status codes, headers, and support for more methods. Connections closed after each request.

HTTP/1.1

Persistent connections, pipelining, caching improvements, and host headers became standard.

HTTP/2

Introduced multiplexing, header compression, and binary framing for faster performance.

HTTP/3 and QUIC

Uses QUIC instead of TCP, reducing latency and improving reliability over modern networks.
