Early Versions of HTTP

HTTP/0.9 was the first version of HTTP. It only supported simple GET requests and returned HTML only.

HTTP/1.0 and HTTP/1.1

HTTP/1.0 introduced headers and status codes. HTTP/1.1 added persistent connections, caching, and more improvements.

Modern HTTP: HTTP/2 and HTTP/3

HTTP/2 uses multiplexing and binary framing for faster performance. HTTP/3 uses QUIC protocol to reduce latency and improve reliability.
