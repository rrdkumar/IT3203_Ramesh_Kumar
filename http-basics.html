What Is HTTP?

HTTP is how a web browser talks to a server. The browser sends a request, and the server sends a response. This is how websites load information for users.

How HTTP Works

When you open a website, your browser sends an HTTP request. The server receives the request, finds the right information, and sends back an HTTP response.

Request Methods

MethodDescription
GETGet information from the server.
POSTSend information to the server.
PUTUpdate a resource.
DELETERemove a resource.

Status Codes

  • 200 OK – The request was successful.
  • 404 Not Found – The page does not exist.
  • 500 Server Error – Something went wrong on the server.
