What Is HTTP?

HTTP is an application-level protocol used for communication between software systems. A browser or application acts as a client and sends an HTTP request. A web server or service processes the request and returns an HTTP response.

How HTTP Works

  1. The client identifies the target resource.
  2. The client sends an HTTP request to the server.
  3. The request may pass through proxies or caches.
  4. The origin server processes the request.
  5. The server sends back an HTTP response.

Request Methods

MethodDescription

Status Codes

  • 1xx — informational
  • 2xx — success
  • 3xx — redirection
  • 4xx — client errors
  • 5xx — server errors
