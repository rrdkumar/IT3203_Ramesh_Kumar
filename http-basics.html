Early Versions of HTTP

HTTP/0.9 was the first version of HTTP. It only supported simple GET requests and could return HTML documents.

HTTP/1.0 and HTTP/1.1

HTTP/1.0 introduced important features such as headers and status codes. HTTP/1.1 improved efficiency through persistent connections, caching, virtual hosting support, and additional protocol enhancements.

Modern HTTP: HTTP/2 and HTTP/3

HTTP/2 introduced multiplexing and binary framing, allowing multiple requests to be processed over a single connection. HTTP/3 further improves performance by using the QUIC protocol, reducing latency and improving connection reliability.
